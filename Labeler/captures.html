Keys
Every tile needs a box and nothing else does. Click empty space to add a box the size of those nearby, or drag to draw one; drag a box to move it, its corner to resize. Click a box to select it, shift-drag around several to select them, or a to select every unconfirmed one. Type a tile (r12, j) and Enter to set and confirm it, ? for one you can't read, or just Enter to confirm what it shows; one box then goes on to the next unconfirmed. ←→ turn its orientation, ⌫ deletes it, Esc selects none. With nothing selected, Enter marks the capture done and opens the next, u unmarks it, and D deletes it, to the Trash. Under Check, dashed red marks a box the finder misses, dashed blue a box it finds that has none (double-click to adopt it), and a red tag a value the classifier reads otherwise. n zooms to the next mark, N the previous, drawing the finder's box there solid; f snaps the selected box to it, or adds it, or with no mark snaps the selected box to the finder's box it overlaps. Tab selects the next unconfirmed box; Enter with nothing selected marks the capture looked over. +− zoom, 0 fit. [] previous and next capture.

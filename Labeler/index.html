Keys
Every tile needs a box and nothing else does. Click empty space to add a box the size of those nearby, or drag to draw one; click one and ⌫ to delete it, or shift-drag a rectangle around several and ⌫; drag a box to move it, its corner to resize. Enter marks the capture done and opens the next. Values are optional: click a box, type its tile (r12, j) and Enter, or just Enter to confirm the value it shows; either goes on to the next box without one. Esc deselects, so Enter marks the capture; u unmarks it. Under Check, dashed red marks a box the finder misses, dashed blue a box it finds that has none (double-click to adopt it, or f on a box to snap it to the one it overlaps), and a red tag a value the classifier reads otherwise. n zooms to the next mark, N the previous; Tab selects the next box without a value; Enter marks the capture looked over. ←→ turn which way is up. +− zoom, 0 fit. [] previous and next capture.
